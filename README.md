# FELICIA 1박 2일

중창단 FELICIA의 첫째 날 밤 프로그램. 정적 웹 페이지 세 장이라 무료로 배포됩니다.

| 페이지 | 누가 보나 | 용도 |
|---|---|---|
| `index.html` | 단원 7명 | 표지와 세 갈래 입구 |
| `voice.html` | 단원 7명 | 목소리 지문 로고 — 보기와 내려받기 |
| `wrapped.html` | 단원 7명 | 우리의 결산 18장 |
| `mycheers.html` | 단원 7명 | 나에게 온 응원 (확인 코드 필요) |
| `host.html` | 운영자 (박은태) | 지문 만들기 · 결산 상영 · 응원 전체 확인 |
| `cheer.html` | 응원해주시는 분들 | 단원을 골라 응원 메시지 남기기 |

팀 데이터(단원, 연습 횟수, 무대 기록 등)는 `assets/app.js` 맨 위 `TEAM` 한 곳에만 있습니다. 여기만 고치면 세 페이지에 전부 반영됩니다.

## 1. 로고

`assets/logo.png` — 1000×1000 투명 배경 PNG가 들어가 있습니다. 획 색 `#F8D870` 을 페이지 기준색으로 쓰고 있습니다.

로고를 교체하면 `assets/app.js` 의 `LOGO_GEOM` 을 다시 맞춰야 합니다. 원형 링의 중심 x, y 와 반지름을 이미지 크기에 대한 비율로 적은 값이고, 지문 링이 이 원과 동심을 이루도록 쓰입니다. 현재 값은 픽셀에서 실측한 `{ cx: 0.4985, cy: 0.3770, r: 0.2712 }` 입니다.

파일이 없으면 비슷한 도형(삼중 링 + F + 워드마크)으로 대신 그리므로 페이지는 그대로 동작합니다.

## 2. 저장소 만들기 (무료, 5분)

응원 메시지와 목소리 지문을 여러 기기가 함께 보려면 저장소가 필요합니다. Google 스프레드시트 + Apps Script를 쓰면 계정 하나로 무료입니다.

1. [script.google.com](https://script.google.com) 에서 새 프로젝트를 만들거나, 스프레드시트의 **확장 프로그램 → Apps Script** 로 들어갑니다. 어느 쪽이든 됩니다 — 스크립트가 시트를 알아서 잡고, 없으면 내 드라이브에 하나 만듭니다.
2. 기본 코드를 전부 지우고 이 저장소의 **`backend.gs` 내용을 붙여넣고** 저장합니다.
3. 우측 상단 **배포 → 새 배포**.
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 응원해주시는 분들이 로그인 없이 쓰려면 반드시 이것
4. **배포**를 누르고 권한을 승인하면 `https://script.google.com/macros/s/.../exec` 주소가 나옵니다. 그 주소를 `assets/app.js` 의 `ENDPOINT` 에 넣습니다. (이미 넣어져 있습니다.)

데이터가 어느 시트에 쌓이는지 확인하려면 웹앱 주소 뒤에 `?kind=info` 를 붙여 브라우저로 열어보세요. 시트 주소가 나옵니다.

`ENDPOINT` 를 비워두면 페이지가 각 기기의 브라우저에만 저장합니다. 혼자 시험해볼 때는 괜찮지만, **단원들과 응원 메시지를 함께 보려면 반드시 채워야 합니다.** 비어 있으면 페이지 상단에 경고가 뜹니다.

> 코드를 고친 뒤에는 Apps Script에서 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 반영됩니다. 새 배포를 만들면 주소가 바뀌므로, 기존 배포를 수정하세요.

### 누구나 쓸 수 있는 주소입니다

응원해주시는 분들이 로그인 없이 남길 수 있어야 하므로 이 주소는 공개입니다. 원리상 누구나 메시지를 추가할 수 있습니다. 하는 일은 시트에 한 줄 추가하는 것뿐이고, 이상한 메시지가 들어오면 스프레드시트에서 그 줄을 지우면 됩니다.

## 2-2. 단원 확인 코드

`mycheers.html` 은 네 자리 코드로 누구인지 확인하고, **그 사람에게 온 응원 + 모두에게 온 응원**만 보여줍니다. 한 번 넣으면 그 기기에 기억되고, 「내가 아닙니다」로 지울 수 있습니다.

코드 원본은 이 저장소에 들어 있지 않습니다. `assets/app.js` 에는 `felicia:<단원id>:<코드>` 의 SHA-256 앞 32자만 있습니다.

**이 코드는 자물쇠가 아닙니다.** 네 자리는 만 가지뿐이라 작정하면 전부 시도해볼 수 있습니다. 소스를 열어본 사람이 코드를 바로 읽지 못하게 막는 수준이고, 서로의 응원을 실수로 보지 않게 하는 칸막이입니다. 응원 내용이 민감하다면 이 방식으로는 부족합니다.

코드를 바꾸려면 브라우저 콘솔에서 새 해시를 만들어 `CODE_HASH` 의 해당 줄을 교체하세요.

```js
// 예: 박수민(sumin) 코드를 4821 로 바꿀 때
crypto.subtle.digest("SHA-256", new TextEncoder().encode("felicia:sumin:4821"))
  .then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2,"0")).join("").slice(0,32)));
```

## 3. 배포

### GitHub Pages

```bash
gh repo create felicia --public --source=. --push
```

그다음 저장소 **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)** 로 두면 1~2분 뒤 이 주소에서 열립니다.

```
https://<사용자이름>.github.io/felicia/
```

파일을 고친 뒤 다시 올릴 때:

```bash
git add -A && git commit -m "update" && git push
```

### 다른 무료 호스팅

폴더를 그대로 끌어다 놓으면 되는 곳들입니다. 빌드 설정은 필요 없습니다.

## 4. 진행 순서

**여행 며칠 전**

1. `cheer.html` 주소를 응원해주실 분들께 보냅니다. 단체 카톡방이 좋습니다.
2. 단원 7명에게 각자 휴대폰 음성 녹음기로 **15~30초** 녹음을 부탁합니다. 편한 음 → 낮은 음 → 높은 음을 한 번씩 내게 하면 음역이 제대로 측정됩니다.
3. 녹음 파일을 모아 `host.html` 의 **지문** 탭에서 한 명씩 분석합니다. 여기서 측정된 음역이 결산 개인 슬라이드에도 들어갑니다.
4. **전체 백업 내려받기**로 `felicia-prints.json` 을 받아 보관해두세요.

**첫째 날 밤, 저녁 식사 후**

1. 노트북을 TV에 연결하고 `host.html` → **결산** 탭.
2. `←` `→` 키로 슬라이드를 넘깁니다. 총 18장입니다.
3. 결산이 끝나면 단원들에게 `index.html` 주소와 **각자의 확인 코드**를 보냅니다. 각자 휴대폰에서 자기 지문 로고를 저장하고, 자기에게 온 응원을 읽습니다.

### push 가 403 으로 막히면

이 저장소는 `dmsxo0691` 계정 소유인데 Windows 자격 증명 관리자가 다른 계정을 물고 있을 수 있습니다. 이 저장소에만 `gh` 를 자격 증명 도우미로 지정해 두었습니다.

```bash
gh auth switch --user dmsxo0691
```

`gh` 의 활성 계정이 `dmsxo0691` 이면 `git push` 가 그대로 됩니다.

`backend.gs` 와 `README.md` 는 웹에서 쓰이지 않습니다. 공개 저장소가 신경 쓰이면 배포 폴더에서 빼도 됩니다.
